# Model availability

Two final PPO model directories are bundled because their weights are small and are directly referenced by the documented experiments:

- `ppo_mix_v3_sd`
- `ppo_mix_v3_no_sd`

Each directory contains the final `.pt` weight file and its training records and plots.

Historical and intermediate checkpoints from the working tree are intentionally excluded from GitHub. If they are needed for public reuse, publish them in a separate model repository and add the stable URL, version, license, and SHA-256 checksums below.
